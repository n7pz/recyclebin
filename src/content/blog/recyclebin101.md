#### Hi everyone,

This post will serve as some sort of explanation/guide for how, why and what I will use this blog I built for.

It has been a while since I started gaining lots of interest on scavenging through things like modding games, in my case I started with porting maps from older browser racing games to BeamNG, which later devolved into basically starting to learn how these older engines worked.

I wanted a place where I could document things involving these little projects I've been working on, but also wanted to turn this website onto a project and ended up deciding that I might aswell add whatever I do with my studies and learn by myself on that same note.

So this blog will be basically a mix of the former: I will talk about projects such as porting older Unity/Shockwave 3D assets to Blender, and whatever games I import these to, reversing files of these games (and probably other programs that are not games!). And also whatever I investigate involving cybersecurity and the content I learn while studying.

I will try to keep it informal and at least have some of the posts reach a comedic degree.  
<small><i>(But you never know if you have to show your personal projects for school so I'll keep it mildly professional)</i></small>

As of writing this I haven't pushed the project to Git yet, sorry if it looks ugly or unfinished, it's my first time building a website w/ Astro.
Posts here are written in Markdown and published through Astro. Some posts might contain code, screenshots, experiments, or whatever else is useful for documenting what I'm doing.

 Needless to say this will always be a work in progress as I will be restyling and adding features according to my necessities. Expect some new posts coming really soon (hopefully)

And for now that's pretty much it.. Since this post will be pinned for orientation I will keep it updated if any changes arise. 

### **See you soon!**
